Resonance: A Plague Tale Legacy Trainer

A free, open-source trainer for Resonance: A Plague Tale Legacy on Windows. It attaches to the running game on its own and gives you infinite health, invisible.

Options for Resonance: A Plague Tale Legacy

Every option in the Resonance: A Plague Tale Legacy script, with the shortcut that toggles it in game. Turning the trainer off restores the game exactly as it was.

OptionSettingShortcut
Infinite Health On / off Alt+F1
Invisible On / off Alt+F2

The script is read before it runs and is never hidden from you: see configs/games/resonance.js. Resonance: A Plague Tale Legacy was released on 27 August 2026; the trainer checks the build it attaches to and stays out of the way when it does not recognise it.

How to use it

1

Download

Save az_trainer.exe in a folder of its own. On first launch it fetches the game scripts, including this one.

2

Start Resonance: A Plague Tale Legacy

AZ Trainer recognises the running game and its version, then attaches by itself.

3

Pick your options

Tick them in the window or use the shortcuts above. Closing the trainer reverts every change.

Windows SmartScreen warning. On first launch Windows may report that Microsoft Defender SmartScreen prevented an unrecognized app from starting. AZ Trainer is not code-signed, so new releases have not yet built up download reputation. Select More info, then Run anyway. To confirm the file is genuine, compare Get-FileHash az_trainer.exe with az_trainer.exe.sha256 on the release page.
